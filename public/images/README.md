# Images for 4M International

Drop your real photos into this folder using the **exact filenames** below.
Until a file exists, the site shows a neutral grayscale placeholder, so the
layout always looks complete. No code changes are needed — just add the file.

All photos look best **dark, cinematic, and a little moody** (the site is a
dark theme with a gold accent). Landscape unless noted. Higher resolution is
better; they are displayed large and full-bleed.

| Filename | Where it appears | Suggested size | What to shoot / source |
|---|---|---|---|
| `hero.jpg` | Full-screen homepage hero | 2000×1200+ | A strong establishing shot of the group: a modern building, an aerial of farmland/industry, or a wide cityscape of Dhaka at dusk. Should have darker areas (top + bottom-left) so white text stays readable. |
| `about.jpg` | "About Us" section | 1200×1500 (portrait) | People at work, a handshake, a boardroom, or a signature building. Conveys leadership + scale. |
| `founder.jpg` | "The Founder" section | 1200×1500 (portrait) | A clean, well-lit portrait of the founder/owner (head & shoulders, looking confident). |
| `company-oushod-sheba.jpg` | Oushod Sheba panel | 1700×1300 | Pharmacy, medicine production, healthcare, or pharmacist with patient. |
| `company-4m-agro.jpg` | 4M Agro panel | 1700×1300 | Farmland, crops, greenhouse, livestock, or agro-processing line. |
| `company-zaag-system.jpg` | Zaag System panel | 1700×1300 | Servers, code on screens, a data centre, or engineers at workstations. |
| `company-hardware-sanitary.jpg` | Hardware & Sanitary panel | 1700×1300 | Hardware/tools, plumbing fittings, sanitaryware showroom, or a warehouse. |
| `company-trading.jpg` | 4M Trading panel | 1700×1300 | Shipping port, containers, cargo, or a logistics/warehouse scene. |
| `presence.jpg` | "Headquartered in Dhaka" | 1900×1150 | The HQ building exterior, or an evocative Dhaka cityscape. |

## Tips
- JPG or WebP both fine (keep the `.jpg` name, or update the path in `src/data/site.js`).
- If you only have a few images to start, add them in any order — the rest stay on placeholders.
- Want a different crop emphasis? Tell me and I'll adjust the focal point.
